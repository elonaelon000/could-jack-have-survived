def observed(data: pd.DataFrame, keys: list[str] | str) -> pd.DataFrame:
    return data.groupby(keys, observed=True, dropna=False).Survived.agg(
        survived='sum', passengers='count', rate='mean'
    )

def jack_like(data: pd.DataFrame) -> pd.DataFrame:
    return data.loc[(data.Sex == 'male') & (data.Pclass == 3) & data.Age.between(18, 25)]

def young_men(data: pd.DataFrame, low: int = 18, high: int = 30) -> pd.DataFrame:
    return data.loc[(data.Sex == 'male') & data.Age.between(low, high)]

def adults(data: pd.DataFrame) -> pd.DataFrame:
    return data.loc[data.Age.between(18, 50)]

def family_group(data: pd.DataFrame) -> pd.DataFrame:
    people = data.loc[(data.Sex == 'male') & (data.Pclass == 3) & data.Age.between(18, 50)].copy()
    people['RecordedRelatives'] = (people.SibSp + people.Parch) > 0
    return people

def wilson(successes: int, total: int, z: float = 1.96) -> tuple[float, float]:
    """Approximate 95% Wilson interval for the observed binary rate."""
    if total <= 0:
        return float('nan'), float('nan')
    p = successes / total
    denominator = 1 + z*z/total
    midpoint = (p + z*z/(2*total))/denominator
    half = z*sqrt(p*(1-p)/total + z*z/(4*total*total))/denominator
    return (0.0 if successes == 0 else max(0.0, midpoint-half),
            1.0 if successes == total else min(1.0, midpoint+half))

2. Three hypotheses — written before outcome exploration

Fixed Jack-like proxy: male, third-class passenger, 18–25 inclusive, recorded age. This operational definition cannot identify a fictional character. Wider age bands are allowed only as labelled exploratory sensitivity checks, not changes to the registered hypotheses.

H1 · Sex (directional): Among passengers aged 18–50 inclusive, women have higher observed survival rates than men within each passenger class. Test: compare female and male rates independently in classes 1, 2, and 3; report all denominators.

H2 · Class (directional): Among men aged 18–30 inclusive, first-class passengers have higher observed survival rates than third-class passengers. Test: compare first vs third with denominators and a percentage-point difference; show the second class too when interpreting the overall class gradient.

H3 · Recorded relatives (directional): Among third-class men aged 18–50 inclusive, passengers with SibSp + Parch > 0 have higher observed survival rates than those with SibSp + Parch == 0. Test: compare recorded-close-relative groups with counts and rates. Zero is NOT proof of travelling alone.

Decision criterion: SURVIVED means the observed direction agrees with the stated hypothesis; NOT SUPPORTED means it does not. Neither label is a population-level significance claim, and small samples must be disclosed. The original operational definitions and directional claims are preserved; consult the first commit for the original wording.

Why these age windows? A later methodological clarification

This explanation was added on 19 October 2026, after analysis. The cutoffs themselves are already present in the original hypothesis commit; this note is not new preregistration or a claim of statistically optimized cutoffs.

Window Purpose
18-25 Closest Jack-like baseline: male, third class, known age.
18-30 H2: compare first- and third-class young men; show second class too.
18-50 H1: compare women and men within each class. H3: compare recorded relatives among third-class men.

These are overlapping analysis windows, not disjoint age categories. Endpoints are inclusive. Unknown ages are excluded only from age-dependent subsets, not deleted from the source dataset. The narrower window favors similarity to Jack; wider windows add passengers but are less specific to him. More observations do not automatically make a comparison better, and sharing an age window does not fully adjust for age.

The website selector changes only the age filter, not the entire hypothesis test. First-class men 18-25 number 10; at 18-30 they number 22. These observed counts illustrate the trade-off, not an outcome-based justification for the original choice.

6. Three evidence-backed problems with the dataset

The task is to prove problems, not merely report there are blanks. The three problems below are quantified and each directly affects the Jack question.

Problem 1 — Ages are systematically unevenly recorded across groups. Missingness changes the denominator of every Jack-like analysis. Compare the missing share by sex/class and by recorded survival outcome. This is evidence against treating known ages as a simple representative cross-section, not proof of why ages are missing.

Problem 2 — The Cabin column is not a reliable proxy for where passengers were located. It is missing for the great majority of passengers, especially lower classes; comparisons restricted to known cabins would select a very different mix of travellers.

Problem 3 — Tiny comparison groups make dramatic rates fragile. The first-class young-men group has only 22 people and the family-positive third-class adult-male group has 33. Show denominators and approximate intervals; do not turn rate gaps into individual predictions.

An additional scope limitation: the 891 Kaggle training records exclude competition-test passengers and crew, and there is no lifeboat access or evacuation timeline.
